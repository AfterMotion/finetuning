Foundations 03

Accessibility & Contrast Matrix

Every color pairing is verified mathematically using relative luminance formulas. WCAG 2.1 AA and AAA standards are strictly enforced.

Foreground Token Background Surface Contrast Status Engineering Enforcement Rule
#070D18 (Obsidian) #F09320 (Solar Amber) 8.24 : 1 ✓ AAA PASS MANDATORY text on Amber buttons. Never use white text.
#F09320 (Solar Amber) #FFFFFF (White Canvas) 2.36 : 1 ✕ FAIL TEXT Forbidden for normal text. Permitted for decorative icons only.
#2B5E70 (Dark Teal) #FFFFFF (White Canvas) 7.15 : 1 ✓ AAA PASS MANDATORY for teal text, badges, and links on light mode.
#F8FAFC (Slate 50) #070D18 (Midnight Stage) 18.10 : 1 ✓ AAA PASS Primary body copy and headlines in dark mode.
#0F172A (Slate 900) #FFFFFF (Studio Light) 17.85 : 1 ✓ AAA PASS Primary body copy and headlines in light mode.
